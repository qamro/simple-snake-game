# 🐍 Snake Game  Python & Pygame

**A simple classic Snake Game developed using Python and Pygame. Control the snake, collect food, increase your score, and avoid colliding with yourself or the walls!**

# Running

To run the game just:

**Clone the repo** 

then:

**execute these two commands(this for activate the virtual environment and run the game):**
- source venv/venv/bin/activate                                           
- python main.py
